# Number Guessing Game
A simple command-line C++ game where the computer picks a random number between 1 and 20, and the player tries to guess it within 5 attempts.
## Features
-Random number generation
-Feedback: "Your guessed number is above my chosen number. Try again/Your guessed number is below my chosen number. Try again"
-Tracks number of attempts
-Limited to 5 attempts
## How to Play
1. Compile with any C++ computer
2. Run the executable
3. Follow the on-screen instructions
4. ## Example
5. Hi,Welcome to the guessing game! What's your name?
6. I've chosen a number from 1 to 20. Ready to guess?
7. You have just 5 attempts to guess it right!
8. Enter your guessed number from 1 to 20 : 10
9. Your guessed number is above my chosen number. Try again.
10. ...
11. Wow! Congratulations! You've guessed it right.
12. ### Concepts Used
13. - Loops (do-while)
    - Conditionals (if-else)
    - Random number generation
    - User input/output
